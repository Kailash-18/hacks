ABOUT THE PHYSICAL LAB PHOTO-LED REVERSE ENGINEERING

A closer read of
the object in front of you.

Turn object photos into an explorable study. Follow each part back to its visible evidence, see which details are inferred, and inspect how the pieces relate.

01 / EVIDENCE

Start with the photograph.

Use up to four views of one object. Parts identified in the image stay distinct from components inferred beyond the visible surface.

02 / DEPTH

Give the image layers.

Photo cutouts can be arranged into a depth view in the browser, so you can rotate, isolate, and inspect the object's visible structure.

03 / CONNECTIONS

Trace how parts relate.

Explore part details, linked components, and analysis grounded in the selected study. Treat estimated depth and inferred internals as interpretation.
